# SIPERKA - Sistem Pelaporan Kerusakan Fasilitas Kampus
Proyek Praktikum Pemrograman Web (OBE 2026) - Pertemuan 2  
Program Studi Sarjana Teknik Komputer, Universitas Borneo Tarakan

## Deskripsi Singkat
SIPERKA adalah sistem pelaporan fasilitas kampus berbasis web yang dirancang menggunakan standar semantik HTML5 dan aksesibilitas dasar (WCAG 2.1).

## Cara Menjalankan Menggunakan Laragon 5
1. Jalankan aplikasi Laragon dan klik **Start All**.
2. Pastikan proyek berada di direktori `C:\laragon\www\pemweb-obe` (atau `D:\laragon\www\pemweb-obe`).
3. Buka browser dan akses URL: `http://localhost/pemweb-obe/`

## Checklist Aksesibilitas Dasar
| Parameter | Implementasi pada Kode | Status |
| :--- | :--- | :---: |
| `lang` | Menggunakan `<html lang="id">` untuk bahasa Indonesia | ✓ |
| Heading | Terstruktur runtut dari h1, h2, hingga h3 | ✓ |
| `alt` | Gambar informatif memiliki deskripsi jelas, ikon dekoratif alt="" | ✓ |
| Label Form | Setiap input terhubung dengan label via for dan id | ✓ |
| Teks Link | Deskriptif (misal: "Alur Layanan", "Pusat Bantuan") | ✓ |
| Keyboard | Dapat dinavigasi via tombol Tab dan memiliki skip link | ✓ |
